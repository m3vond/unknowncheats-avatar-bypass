# unknowncheats-avatar-bypass

Bypassing unknowncheats.me avatar restrictions.

---------------------

## Transparent Image
- Open up photoshop and create `1x1` blank image.
- Remove the background to make it transparent.
- Save as jpeg.

## Instructions
- Go to user control panel and select `Change Avatar`.
- Press `CTRL + SHIFT + I` and paste the code from bypass.js.
- Select your `1x1` avatar file.
- Click save changes.
